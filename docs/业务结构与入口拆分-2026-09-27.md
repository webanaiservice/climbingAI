# 训练中心与运营中心入口拆分

## 本次范围

仅调整 Web 导航、总览入口和定线页面的业务场景，不改定线算法、后端 API、数据表、账号角色或 AI 白名单。

| 业务中心 | 子入口 | 地址 |
| --- | --- | --- |
| 训练中心 | 运动员档案 | `/dashboard/training` |
| 训练中心 | 训练日志 | `/dashboard/training?tab=sessions` |
| 训练中心 | 视频复盘 | `/dashboard/training?tab=review` |
| 训练中心 | 训练任务 | `/dashboard/training?tab=tasks` |
| 训练中心 | 成长报告 | `/dashboard/training?tab=progress` |
| 训练中心 | 训练板定线 | `/dashboard/training/board-setting` |
| 运营中心 | 岩点库 | `/dashboard/assets/holds` |
| 运营中心 | 线路库 | `/dashboard/assets/routes` |
| 运营中心 | AI 辅助定线 | `/dashboard/route-setting` |
| 运营中心 | 视频识别 | `/dashboard/camera` |

总览仍为 `/dashboard`；员工管理仍归系统管理。训练中心页签与侧栏高亮、标题、刷新和浏览器历史同步，非法页签回到运动员档案。星星道与飞鸟道的原有档案、记录、复盘及复测功能保留。

## 定线场景与兼容

- 两个入口复用同一个定线工作台组件；运营入口只开放自由定线及虚拟固定板，训练入口只开放天宇训练板，后续其他实物板可在此扩展。
- 运营入口不加载或迁移天宇板存档；训练入口不读取厂家岩点库或虚拟固定板存档，避免旧虚拟板存档把训练页切到错误模式。
- 天宇板沿用原 `ai-gym.tianyu-board.v2` 键和点位编号，保留已保存的角度、人工坐标及属性；GLB 配准、人工修改、保存和生成参数不变。
- 原有运营网址继续可用；天宇板在原页面内没有独立网址，现使用新入口。AI 开关和邮箱白名单同时约束两个入口，导航隐藏之外仍保留服务端验证。
- 保存仍为当前浏览器本地保存，不会因此获得跨设备同步。候选线路仍按原有方式临时保留，离开定线页面不会自动归档到线路库。

## 验证与发布边界

- Web 59 项测试通过，包含新增导航映射、服务端登录/白名单及场景锁定测试。
- 类型检查和 Next.js 生产构建通过；定线页保留已有 `<img>` 性能提示。
- 隔离浏览器验收覆盖 264 点和旧虚拟板存档、45° 恢复、人工点位保留、GLB 叠加、自由/训练板请求参数、训练页签刷新及后退、移动端导航、无权限与未登录访问。
- 浏览器验收使用临时本地接口和浏览器存储，没有修改真实训练数据，也没有调用外部模型。
- 本地实现与验收已完成。生产发布仅更新 Web，不需要数据库迁移或 API 重启；保留原前端镜像和源码作为回退点，不携带本地测试账号、数据库、视频或密钥。

不包含运动员自助账号、训练板线路服务端归档、攀爬记录与线路版本关联，以及基于运营数据的换线决策。这些留待下一阶段，不在入口拆分时伪装成已实现功能。
